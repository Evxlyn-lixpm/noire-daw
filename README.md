# NOIRÉ — Evaluación Parcial DAW

Proyecto de tienda de moda dark feminine.

## API
```bash
cd api
npm install
npm start
```

API local: http://localhost:3000

## Frontend
Abrir `frontend/index.html` con Live Server.

## Recursos API
- products
- categories
- customers
- orders

## Requisito para Render
Desplegar la carpeta `api` como Web Service y usar:
- Build Command: `npm install`
- Start Command: `npm start`

Luego cambiar `API_URL` en `frontend/js/api.js` por la URL de Render.
