NOIRÉ - FRONTEND

Para probarlo localmente:
1. Abre la carpeta frontend con VS Code.
2. Instala una extensión como Live Server.
3. Abre index.html con Live Server.
4. Asegúrate de tener la API ejecutándose en http://localhost:3000.

IMPORTANTE:
En producción, cambia API_URL en js/api.js por la URL pública de tu API en Render.
